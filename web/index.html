Plaid setup & privacy

Configure Sandbox and Production independently in Plaid settings below. Credentials are sent only to this authenticated application over HTTPS, encrypted before database storage, and never shown again.

The application requests the Transactions product. It has no payment or transfer endpoints. Access tokens are encrypted before storage. Local development uses SQLite; hosted deployments use your private PostgreSQL database and an encryption key supplied through Vercel. This dashboard does not send transaction data to an AI service.

Connections may require reauthentication. Sync retrieves the latest data Plaid already has; it is not a real-time bank refresh. For OAuth banks, register https://js-finances.vercel.app/ in Plaid. Use the same browser tab to return here.
