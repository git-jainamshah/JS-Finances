Plaid setup & privacy

Copy .env.example to .env in this project for local use, or set the matching environment variables in Vercel for hosting. Choose sandbox or production, then restart or redeploy. Never paste credentials into chat.

The application requests the Transactions product. It has no payment or transfer endpoints. Access tokens are encrypted before storage. Local development uses SQLite; hosted deployments use your private PostgreSQL database and an encryption key supplied through environment variables. This dashboard does not send transaction data to an AI service.

Connections may require reauthentication. Sync retrieves the latest data Plaid already has; it is not a real-time bank refresh. For OAuth banks, register a redirect URI in Plaid and set PLAID_REDIRECT_URI. Use the same browser tab to return here.
